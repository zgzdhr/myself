# 关键弹层 UI 复刻验收

参考图：`05-ai-result-confirm.png` 至 `10-delete-confirm-dialog.png`。

## 功能映射

| 参考图 | 当前实现 |
| --- | --- |
| AI 整理确认 / 重复项 | 首页紧凑 extracted item 卡片；确认、编辑、拒绝和去重逻辑不变 |
| 任务编辑 Sheet | 普通任务 / 每日重复、标题、备注、日期、开始/结束时间、清除时间和保存 |
| 复盘补充 Sheet | 采集真实用户 note 后调用 `/review`；当前无心情量表和能量字段，不伪造 |
| 时间规划确认 Sheet | 生成草稿后展示概览和全部时间块，可确认、返回编辑或取消 |
| 删除确认 Dialog | 共享危险操作对话框，提供关闭、取消和确认删除 |

## 已验收

- 弹层统一使用 28–30 px 顶部圆角、拖拽条、白色表面和蓝色主操作。
- 删除操作统一使用红色危险语义，且保留取消和关闭入口。
- 没有为复刻参考图增加当前数据库不存在的心情、能量、标签或提醒字段。
- 所有自动打开弹层、固定日期和固定 Tab 的截图辅助代码均已撤回。
- `flutter analyze` 通过。
- Flutter 全量 171 项测试全部通过。

## 保留差异

- 当前任务模型没有分类标签、提前提醒和独立状态编辑字段，因此任务 Sheet 不展示无效表单项。
- 当前复盘接口只接收补充文字，未加入无法持久化的心情、能量和关键词控件。
- AI 整理确认使用首页内联卡片，而不是额外覆盖一层弹窗，以保留现有连续确认流程。
