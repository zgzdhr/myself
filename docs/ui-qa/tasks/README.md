# 任务页 UI 复刻验收

参考图：`docs/ui-reference/2026-07-11-chatgpt-design/02-tasks.png`

## 设计量取与结构

- 参考图尺寸为 941 × 1672；正文采用约 31 px 左右留白，卡片圆角约 22–28 px。
- 页面纵向结构为：标题区 → 月/周切换 → 月历 → 当日时间线 → 任务列表 → 底部导航。
- 月历约占参考图页面高度的 27%，当日时间线约占 25%，任务列表约占 24%；三段内容必须能在一屏内建立完整信息层级。
- 标题约 32 px，区块标题约 21–24 px，正文约 16–18 px，辅助文字约 13–15 px；Flutter 截图按设备像素比换算为逻辑字号。

## 设计与真实功能映射

| 参考图组件 | 当前真实功能 |
| --- | --- |
| 月视图 / 周视图 | 切换现有月历和支持拖拽的周历 |
| 月份前后箭头、回到今天 | 改变当前选中日期并重新读取数据库 |
| 日期彩色圆点 | 普通任务、每日重复、AI 时间规划的真实日期标记 |
| 当日时间线 | 展示选中日期的任务、重复任务、规划块和久坐会话 |
| 新增任务 | 打开现有任务创建弹层，保留重复任务能力 |
| 全部 / 进行中 / 已完成 / 已取消 | 按真实 `task_status` 筛选任务 |
| 完成 / 恢复 | 写入数据库并同步本地提醒状态 |
| 编辑 / 删除 | 复用原任务编辑和二次删除确认流程 |

## 已验收

- 页面展示层已按参考图重建，不再沿用旧的大型日历布局换色。
- 月视图一屏内可同时看到日历、当日时间线和任务列表。
- 周视图的七日展示与拖拽逻辑仍保留。
- 完成、取消、恢复、编辑、删除、提醒同步均继续操作真实数据。
- `flutter analyze` 通过。
- 任务管理与数据库定向测试共 36 项通过，覆盖状态展示、完成/取消/恢复、编辑、删除和空状态。

## 保留差异

- 参考图使用 2025 年 5 月的多条演示任务；验收截图只显示模拟器现有的 2026 年 7 月真实数据，不写死示例内容。
- 真实数据为空时，时间线展示空状态，而不是伪造参考图中的时间块。
- iPhone 17 动态岛和参考图设备模板不同，顶部安全区高度存在设备差异。
