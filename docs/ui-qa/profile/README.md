# “我的”页 UI 复刻验收

参考图：`docs/ui-reference/2026-07-11-chatgpt-design/04-profile-settings.png`

## 设计量取与结构

- 参考图尺寸为 941 × 1672，主体左右留白约 94 px，分组卡片圆角约 20 px。
- 页面结构为：登录状态页头 → 今日概览四列卡 → 四个快捷入口 → 六组直接可见的设置行 → 底部导航。
- 页头头像约 72 px，设置按钮约 48 px；分组标题约 19 px，设置行标题约 16 px，右侧说明约 13–15 px。
- 设置区不是文件夹目录，而是低密度、可快速扫读的两行分组。

## 设计与真实功能映射

| 参考图组件 | 当前真实功能 |
| --- | --- |
| 登录 / 注册 | 打开现有 Supabase 邮箱 OTP 登录 |
| 右上角设置 | 账号高级操作：同步、恢复、删除云端副本、退出和注销 |
| 待办任务 | 读取真实 active tasks 数量 |
| 记录条数 | 当日有效短期状态与生活事件数量之和 |
| 专注时长 | 当前无可靠专注统计，不伪造；映射为待确认条目数 |
| 记忆活跃度 | 当前无活跃度算法，不伪造；映射为已确认长期画像数 |
| 通知 / 同步 / 隐私 / 记忆 | 复用通知权限、云端同步、隐私页和记忆管理入口 |
| 六组设置 | 映射账号、任务、复盘、AI、隐私和 App 现有能力 |

## 已验收

- 账号卡已并入页头，设置分组不再使用旧文件夹式折叠结构。
- 概览只展示可由当前数据库可靠计算的数据。
- 登录、同步、恢复、删除云端、退出和注销能力仍可访问。
- 截图后 App 默认入口和列表滚动位置已恢复。
- `flutter analyze` 通过。
- App Shell 4 项页面与导航测试通过，覆盖复盘入口、“我的”页分组及返回切换。

## 保留差异

- 当前没有专注时长与记忆活跃度算法，因此对应位置使用待确认数和长期画像数。
- 未配置 Supabase 时按真实状态显示“登录 / 注册”和“未配置”，不伪造已同步状态。
- iPhone 17 动态岛使顶部安全区高于参考图设备模板。
