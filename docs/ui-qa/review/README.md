# 复盘页 UI 复刻验收

参考图：`docs/ui-reference/2026-07-11-chatgpt-design/03-review.png`

## 设计量取与结构

- 参考图尺寸为 941 × 1672，主内容左右留白约 92 px，卡片圆角约 20–24 px。
- 页面结构为：标题区 → 每日复盘/时间规划切换 → 日期选择 → 当天数据指标 → 总结/鼓励/不足/建议 → 时间规划预览 → 底部导航。
- 标题约 31 px，模块标题约 20–23 px，正文约 16–18 px，辅助信息约 13–15 px；实现按 iPhone 17 设备像素比换算为逻辑字号。
- 指标区为等宽四列；总结为通栏，鼓励与不足为双列，任务建议再次通栏。

## 设计与真实功能映射

| 参考图组件 | 当前真实功能 |
| --- | --- |
| 日期标题 / 切换日期 | 打开系统日期选择器并读取该日真实记录 |
| 任务完成 | 根据 `task_status` 计算完成数 / 当日任务总数 |
| 专注时长 | 当前没有可靠专注数据，不伪造；映射为短期状态数量 |
| 记录条数 | 读取当日生活事件数量 |
| 心情评分 | 当前没有心情量表，不伪造；映射为复盘来源数量 |
| 今日总结、鼓励、不足、任务建议 | 展示 `/review` 生成并保存在本地的真实 Summary 字段 |
| 编辑、重新生成、删除 | 复用现有编辑、AI 生成和删除流程 |
| 时间规划草稿 | 同页预览真实 `schedule_plan` 与 `schedule_blocks` |
| 查看/编辑时间块 | 切换到现有时间规划 Tab，保留确认和编辑能力 |

## 已验收

- 已移除与参考图不一致的月份周文件夹信息架构。
- 每日复盘首屏按真实日期、指标、总结和时间规划组织。
- 不存在的数据不使用演示数值伪造。
- 复盘日期和 App 默认入口在截图后均已恢复为正常运行逻辑。
- `flutter analyze` 通过。
- App Shell 4 项导航与页面结构测试通过；数据库定向测试在本轮联合验证中通过。

## 保留差异

- 产品目前没有可靠的专注时长和心情评分数据，使用状态数和来源数承接对应位置。
- 参考图中的示例内容与本地真实记录不同；截图使用本机数据库已有内容。
- iPhone 17 动态岛导致顶部安全区高于参考图设备模板。
