## 已验收

- 顶部品牌、问候、输入、快捷入口、整理结果、久坐、今日行动和 AI 建议顺序与参考图一致。
- Debug 日期能力折叠在右上角菜单，不再占用正常页面空间。
- 首页结果使用横向紧凑卡片，确认、编辑和撤销逻辑仍复用原控制器。
- 今日任务只读取真实数据库内容，不为截图写死数据。
- `flutter analyze` 通过。
- 首页、输入确认和建议相关 38 项测试通过。

## 保留差异

- 当前账号模型没有可靠用户昵称来源，因此没有照搬参考图中的 `Zgzdhr`。
- 头像是本地绘制的风格化占位，后续有正式品牌资产时再替换。
- 参考图使用生成的示例数据，模拟器截图按真实本机数据数量展示。
- iPhone 17 动态岛和安全区与参考图设备模板不同，顶部绝对位置存在设备差异。
