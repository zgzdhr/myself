## 视觉语言摘要

- 背景：白色到浅蓝色的柔和渐变，顶部有低对比度圆形光晕。
- 主色：明亮蓝色；辅助色使用绿色、橙色、紫色区分内容类型。
- 容器：白色卡片、较大圆角、细描边和轻柔蓝灰阴影。
- 导航：四个主入口加中央圆形新增按钮；当前项目仍保留现有四栏信息架构，是否增加中央按钮在实现时单独评估。
- 交互状态：待确认、草稿、已确认、完成、取消和删除必须有清晰区别。
- 实现原则：参考视觉层级和布局，不照搬图片中与当前产品功能不一致的虚构数据或入口。
